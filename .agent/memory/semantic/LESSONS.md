- When a function's return tuple grows (e.g. `insert_event()` 2-tuple → 3-tuple → 4-tuple), grep the ENTIRE codebase for all call sites that unpack the return value — not just the obvious ones. A single `row_id, safe_payload = await bus.insert_event(...)` in a caller you missed breaks CI silently. Pattern: before changing any return signature, run `grep -rn "insert_event" --include="*.py" .` and audit every unpack site. The cost of one missed caller exceeds the cost of auditing all of them.  <!-- status=accepted confidence=0.95 evidence=2 id=lesson_pr211_001 -->
- `asyncio.get_event_loop().run_until_complete()` raises `RuntimeError: no current event loop` in Python 3.11+ worker threads (threads created by `run_in_executor()` have no default event loop). A broad `except Exception:` around it silently masks the failure — the init function appears to complete but leaves the singleton `None`. Fix: use `asyncio.run(coro)` instead, which creates and tears down a fresh event loop deterministically. Cannot call `asyncio.run()` twice in the same thread; design worker-thread init functions as one-shot.  <!-- status=accepted confidence=0.95 evidence=2 id=lesson_pr211_002 -->
- SQLite schema migration `ALTER TABLE` blocks must catch `sqlite3.OperationalError` (duplicate column) specifically, not bare `Exception`. Bare `except Exception:` masks real migration failures (disk full, corrupt DB, locked table) and swallows them as "column already exists". Preserve idempotency with specific exception types; let everything else propagate to the caller.  <!-- status=accepted confidence=0.9 evidence=2 id=lesson_pr211_003 -->
- `INSERT OR IGNORE` with `cursor.rowcount == 0` is the correct idempotent dedup pattern for cross-peer event replay. When `IGNORE` fires on a duplicate `event_uuid` (UNIQUE index), `cursor.rowcount` is 0 and `cursor.lastrowid` is stale — do not return it. Instead, SELECT the existing row by `event_uuid` and return its `id` for idempotent operation. This avoids a race-prone SELECT-then-INSERT sequence.  <!-- status=accepted confidence=0.9 evidence=2 id=lesson_pr211_004 -->
